
Approach:
* Require a module by referencing it with gl.require()
* Loads the module synchronously and puts it in script tag
+ Simple
- Uses synchronous loading
- Does not cope well with deferred scripts and dynamically created scripts

Example:
gl.require(
{type:'text/javascript', src:'../src/selector.js'},
{type:'text/javascript', src:'../src/jsunit.js'},
);


Approach:
* Defining a module
* Code implemented in function enclosure (good practice)
* Function enclosure is passed to module function
* So that it can be invoked asynchronously
* Global object (representing the ‘package’) is specified as string parameter
* in the implementor function, this points to
* solves question of how you specify package context
* lib = new function(){this.x=1} vs. (function(lib){lib.x=1})(lib)


Example:
gl.require




Approach:
Pass dependencies as arguments to initialisor instead of as global
+ Faster
+ Optimises better
+ Dependencies are guaranteed to be correct (no cases where X depends on Y
  which depends on Z, but X also depends on Z without declaring such)
+ Free namespacing (though namespacing isn’t exactly hard otherwise)
- Less purty
- More confusing; level of indirection, variable name not guaranteed
- You probably want global objects anyway
  * so maybe just do both, and evaluate?
  - but then you can’t remove the module-name argument to bb.module


Example:
gl.module(
'unit.selector',
{type:'text/javascript', src:'../src/selector.js'},
{type:'text/javascript', src:'../src/jsunit.js'},
function(oDep1, oDep2) {

var XXX = function() {};
this.XXX = XXX;
XXX.prototype.add = function() {};

});








Approach:
Pass context as first argument instead of using ‘this’
- Less pretty
+ Optimises better (although not much w/ gzip)







gl.require vs. gl.module; compare the code:
===========================================

gl.require(
	{type:'text/javascript', src:'../src/selector.js'},
	{type:'text/javascript', src:'../src/jsunit.js'}
);

unit.selector = new function() {
	var XXX = function() {};
	this.XXX = XXX;
	XXX.prototype.add = function() {};
};

vs.

gl.module(
	'unit.selector',
	{type:'text/javascript', src:'../src/selector.js'},
	{type:'text/javascript', src:'../src/jsunit.js'},
	function() {
		var XXX = function() {};
		this.XXX = XXX;
		XXX.prototype.add = function() {};
	}
);
