Constraints trying to satisfy:

- Using <script src=""> insertion instead of XHR + eval
  - Pro: Allows cross-domain scripts
  - Pro: Plays friendly with Firebug stack traces
- Loading asynchronously
  - Pro: Does not block the browser UI
- Loading scripts in parallel
  - Pro: Efficient use of bandwidth
- Ability to load any plain JavaScript
- Module system encourages wrapping code in function enclosure

Having problems coupling loaded scripts with modules to their URI though, which is necessary in order to properly deal with the URI resolving of relative dependency references.

Perhaps additional constraint is needed:

- Use Java-like package-to-folder system (instead of plain URLs)
  - Pro: no problems determining base URI
  - Con: not very web-like
